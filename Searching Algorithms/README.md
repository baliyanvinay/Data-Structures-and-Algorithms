### 4. Shortest Distance Search
1. Give every node a distance. Start node = 0. Others = Infinity
2. Find the closest unvisited node.
3. Update distances of its neighbors.
4. Mark the node as visited.
5. Repeat until all nodes are visited.
```
Pick A -> Process A's neighbors -> Mark A visited
Pick B -> Process B's neighbors -> Mark B visited
```
